--> git fetch origin

descarrega les últimes actualitzacions del repositori remot
al teu repositori local. 
--------------------------------------------------------------

--> git reset --hard origin/main

fa que la teva branca local quedi exactament igual que la branca remota main de GitHub, eliminant els canvis locals que no coincideixin amb aquesta versió.
- reset = mou la branca actual a un altre commit.
  
- --hard = actualitza també els fitxers locals i l'àrea de preparació.

- origin/main = última versió coneguda de la branca main remota.
